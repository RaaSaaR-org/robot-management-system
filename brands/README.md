# Product brands

Markdown brand references for product communication, presentations, proposals, and design briefs.

## NeoDEM

| File | Use |
|---|---|
| [Product identity](neodem/product.md) | Name, product definition, brand promise, and company relationship |
| [Positioning](neodem/positioning.md) | Audience, customer needs, and value proposition |
| [Messaging](neodem/messaging.md) | Taglines, reusable descriptions, and manufacturer-facing copy |
| [Voice](neodem/voice.md) | Tone, terminology, and writing examples |
| [Visual identity](neodem/visual-identity.md) | Logo, colors, typography, and imagery |
| [Logo alternatives](neodem/logos/README.md) | One growing SVG logo collection, including digital trees and minimal futuristic directions, with a single offline gallery |

This pack consolidates the established NeoDEM brand and adds reusable copy based on the repository's product description. The [brand and design contract](../docs/brand.md) remains authoritative for design rules; the [platform documentation](../docs/platform.md) records capability readiness. Check readiness before publishing feature or hardware claims.

The existing [`brand/`](../brand/_template/README.md) directory holds white-label implementation templates. This `brands/` directory holds product brand documentation.
